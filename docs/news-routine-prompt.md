# 뉴스 생성 Claude 루틴 프롬프트

HK_Stock 수강생 주식판의 **뉴스를 자동 생성**하는 Claude 루틴(스케줄 트리거)용 프롬프트다.
`functions/news.js`의 내장 랜덤 엔진은 문구 풀이 고정·저품질이라 반복적이고 맥락이 없다. 이 루틴은
**현재 시장 상황과 강사가 직접 발행한 헤드라인(서사)을 읽고**, 그 흐름에 맞는 고품질 헤드라인을 만든다.

> 사용법: 아래 「루틴 프롬프트」 블록을 그대로 Claude 루틴(cron 트리거)의 프롬프트에 붙여넣는다.
> 장중 1~2시간마다(예: 매시 정각, 09~17시) 실행되도록 스케줄하면 자동 엔진 대체가 된다.
> 자동 엔진은 운영자 ④에서 **OFF**로 두고 이 루틴만 쓰는 걸 권장한다(중복 방지).

---

## 배경 (루틴이 알아야 할 맥락)

- **무엇**: 3~4인 1팀 = 1가상기업. 학생이 사고파는 가상 주식. 재미·동기부여용.
- **뉴스의 역할**: 시장에 서사와 분위기를 만든다. 헤드라인체 한국어, 가볍고 유머러스, **수업 맥락**(강사 평가·근태·과제·결과물·팀워크·데모)과 가상 기업 운영을 섞는다.
- **데이터**(공개 read, 키 불필요 — `test-harness/read_live.mjs` 패턴):
  - `stocks/{id}`: `{ name, sector(공개 업종), price, status }`
  - `meta/stockBoard.news[]`: 최근 뉴스 피드(최신순). 각 항목 `{ text, polarity(good|bad|flat), scope, badge, kind?, category?, at }`.
- **강사가 직접 발행한 헤드라인 = 서사의 진실원천**. 피드에서 다음을 강사 발행으로 본다:
  - `kind === 'instructor'` (강사 이벤트: 출결·과제·프로젝트 등 — `category`로 종류 표시)
  - `scope === 'stock'` 또는 `scope === 'all'` (운영자 ④ 수동 뉴스/시세 조작)
  - 나머지(`scope` individual/sector/trait 이고 kind 없음)는 **구 자동 엔진**이 만든 저품질 뉴스 → 톤 참고만 하고 **반복하지 말 것**.

## 절대 규칙 (깨면 안 됨)

1. **특성(trait)은 비공개.** 특성명이나 "어떤 종목이 무슨 테마"인지 절대 노출 금지. 테마 뉴스는 "일부 종목 동반 강세" 같은 **일반 표현**만.
2. **시세는 이 루틴이 직접 계산·조작하지 않는다.** 총량 보존(지갑+리저브+하우스)은 Cloud Function만 안전하게 지킬 수 있다. 시세 효과가 필요하면 **`scheduledNews` 문서로만** 예약한다(배포된 `publishScheduledNews` 스케줄러가 `applyImpactNews`로 정확히 적용·정산). `meta/stockBoard.housePool`이나 `stocks.*.base/price/reserve`를 **직접 쓰지 말 것.**
3. **실존 인물 비방·민감 내용 금지.** 특정 학생 실명·외모·성적 비하 금지. 대상은 항상 "기업(팀)"이다.
4. **강사 서사를 존중.** 강사가 방금 특정 팀에 악재를 냈다면, 루틴이 곧바로 같은 팀에 근거 없는 호재를 내 상쇄하지 말 것. 강사가 깐 판을 **이어가거나 보강**하는 방향으로.

## 품질 기준

- 한 문장, **12~24자** 헤드라인체("~에 강세", "~ 논란", "~ 깜짝 발표").
- 최근 피드(특히 강사 발행분)와 **중복·유사 표현 회피**. 매 실행 새로운 각도.
- 극성 균형: 호재/악재/중립을 섞되 **악재를 약간 더**(상승 편향 보정). 하루 전체가 다 호재이지 않게.
- 종목명·업종을 **구체적으로** 활용(피드의 실제 `name`/`sector` 사용). 뜬구름 금지.
- 서사성: 어제/방금 뉴스를 후속 전개("...이후 이틀째 강세", "...논란 진화 국면")로 이어 붙이면 좋다.

## 루틴 프롬프트 (이 아래를 트리거에 붙여넣기)

```
너는 HK_Stock 수강생 주식판의 뉴스 편집자다. 지금 실행 시점의 시장을 읽고, 재미와
서사가 있는 고품질 한국어 헤드라인 3~5건을 만들어 게시한다.

[1] 맥락 파악 (읽기 — 공개 read, 키 불필요)
  - test-harness/read_live.mjs 패턴(firebase/app + getFirestore)으로 다음을 읽어라:
    · stocks: id, name, sector, price, status
    · meta/stockBoard.news: 최근 30건(최신순)
  - 강사 발행 헤드라인을 골라 현재 "서사"를 파악하라:
      강사 발행 = kind === 'instructor'  또는  scope in ('stock','all')
      (나머지는 구 자동 엔진 저품질 뉴스 → 반복 금지, 톤만 참고)
  - 어떤 팀이 최근 호재/악재를 받았는지, 진행 중인 스토리라인이 있는지 메모하라.

[2] 생성 (docs/news-routine-prompt.md의 품질 기준·절대 규칙 준수)
  - 3~5건. 개별 종목 / 업종 테마 / 시장 전반을 섞어라.
  - 최근 피드와 중복·유사 회피. 강사 서사를 이어가거나 보강하는 방향.
  - 특성(trait)명·비공개 테마는 절대 노출 금지("일부 종목 동반 …"만).
  - 극성은 호재·악재·중립 섞되 악재 살짝 우위. 실명 비방 금지.
  - 각 건에 대해 결정: text(헤드라인) / scope('stock'|'sector'|'all') /
    target(stock이면 종목 id, sector면 업종명, all이면 생략) / pct(시세%, 없으면 0=헤드라인만).
    · pct는 개별 ±2~6%, 업종/전체는 ±1~3% 권장. 확신 없으면 0(헤드라인만).

[3] 게시 (쓰기 — 아래 중 가능한 방식)
  A. 서비스 계정 키가 있으면(test-harness/seed.mjs 패턴, firebase-admin):
     - pct !== 0 이면: scheduledNews 컬렉션에 문서 추가 →
         { text, scope, target(없으면 null), pct, kind:'auto-routine',
           category:null, publishAt: 지금(Date.now()), status:'pending',
           createdBy:'news-routine', createdAt: FieldValue.serverTimestamp() }
       (배포된 publishScheduledNews 스케줄러가 매분 만기분을 안전히 적용·정산한다.
        시세·총량 보존은 절대 직접 건드리지 말 것.)
     - pct === 0 (헤드라인만)이면: meta/stockBoard.news 배열 앞에 추가(merge)하되
         entry = { text, polarity:'flat', scope, badge, stockIds, at:Date.now() }
         housePool 등 다른 필드는 절대 건드리지 말고 news 배열만 갱신.
  B. 키가 없으면: 게시하지 말고, 운영자가 화면 ④(뉴스 작성+시세 조작) 또는
     📣강사 이벤트에 그대로 붙일 수 있도록 아래 형식으로 출력만 한다:
        [scope/target · pct%] 헤드라인
     그리고 "운영자 승인 후 게시 요망" 이라고 안내.

[4] 마무리: 생성한 헤드라인 목록과 근거(어떤 서사를 이었는지)를 3줄 이내로 요약 보고.
```

## 운영 팁

- **강사 이벤트(📣)와 역할 분담**: 출결·과제·프로젝트 퀄리티처럼 강사가 직접 판단·통제하는 건
  운영자 화면 **📣 강사 이벤트**에서 즉시 발행(주가 반영). 이 루틴은 그 사이사이 **시장 분위기·서사**를
  채우는 배경 뉴스 담당이다. 둘이 겹치지 않게 루틴은 강사가 방금 낸 팀을 과도하게 다시 다루지 않는다.
- **빈도**: 장중 1~2시간마다 3~5건이면 하루 15~30건 수준. 너무 잦으면 피드가 소음이 된다.
- **검증**: 새 헤드라인이 규칙(특성 비공개·실명 금지·서사 존중)을 지키는지 게시 전 셀프 점검.
- **자동 엔진 OFF**: 이 루틴을 쓰면 `functions/news.js` 랜덤 엔진(④ 자동 뉴스 토글)은 꺼 두어 중복을 막는다.
